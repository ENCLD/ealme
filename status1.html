Våre daglige oppgaver

Dette er oppgavene som har fylt hverdagen vår i praksisperioden så langt.

  • Teste og evaluere Claude Code opp mot ulike arbeidsoppgaver i ServiceNow.
  • Utforske Now Assist og sammenligne resultatene med Claude Code.
  • Koble kildekode til en Personal Developer Instance (PDI) via Source Control.
  • Kjøre og dokumentere test-prompts på både norsk og engelsk.
  • Skrive dokumentasjon fortløpende i dagboken og i prosjekt-repoet på GitHub.
  • Delta i korte statusmøter for å avklare hindringer og planlegge neste steg.

Vårt oppdrag

Målet vårt hos KPMG er å utforske og dokumentere hvordan AI-verktøyet Claude Code kan brukes i utviklingsprosessen på ServiceNow-plattformen. Vi undersøker dette langs fire akser: prompting-strategi, kontekststyring, arbeidsflyt og kvalitetskontroll.

Sluttproduktet skal være praktisk anvendelig veiledning som fremtidige utviklere kan bruke i lignende prosjekter, slik at oppsett av nye applikasjoner i ServiceNow blir raskere og bedre kvalitetssikret.
